# What the client takes from this:
# - no session bootstrap request: the first signed request works without cookies, and OnlyFans
#   sets sess, __cf_bm and _cfuvid on it; the client keeps and sends them from then on;
# - x-bc is required (always sent); user-id is optional for a guest (sent as "0", as the web app does);
# - 400 with error code 401 means the signature was refused (signature_rejected, retried with reloaded
#   rules and a new session); 400 with code 0 is any other bad request (client_error, not retried);
# - 404 "User not found" is not_found (not retried);
# - the 85-field user object is what Fans API returns under "data", minus its two own fields
#   (ofapi_gender, ofapi_gender_confidence).
